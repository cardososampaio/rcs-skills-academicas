# Viabilidade das correções

Gravidade informa o efeito científico do problema; viabilidade informa como ele pode ser resolvido; certeza informa o que se sabe. Não fundir essas dimensões numa nota.

Para problemas estruturais ou principais, registrar a ação, sua condição de execução e a informação ainda necessária. Uma ação pode exigir mais de uma etapa.

| Encaminhamento | Quando usar |
|---|---|
| Esclarecimento do autor | O relato não permite saber qual procedimento ocorreu; solicitar a informação exata |
| Edição com base existente | A correção está sustentada no manuscrito ou material fornecido |
| Verificação externa | A conclusão depende de fonte ou requisito ainda não conferido |
| Nova análise | Dados existentes podem responder, mas o resultado ainda precisa ser produzido |
| Nova coleta | A alegação mantida exige material que a base atual não contém |
| Não reparável com os dados atuais para a alegação mantida | Nem edição nem reanálise disponível sustentam aquela alegação; explicitar o motivo |

Não tratar relato incompleto como prova de pesquisa mal executada. Quando o procedimento pode ter ocorrido, a primeira ação é esclarecê-lo, não inventar sua ausência ou exigir refazer o estudo.

Antes de recomendar nova análise ou coleta, examinar se delimitar a conclusão preserva contribuição defensável. Apresentar alternativas e seus efeitos; não escolher uma nova tese pelos autores. Não chamar todo o manuscrito de irrecuperável porque sua conclusão mais ampla não se sustenta.

Exemplo sintético: uma amostra por conveniência de uma instituição não sustenta estimativa populacional nacional. Se a pergunta admite descrição institucional, delimitar o alcance pode ser viável. Se a estimativa nacional é indispensável, explicitar a necessidade de desenho e dados compatíveis. A seleção por conveniência, isoladamente, não decide entre esses caminhos.

Na passagem de parecer para escrita, conservar localização, evidência, gravidade e ação. Os rótulos da escrita descrevem consequências para a entrega; não há correspondência automática entre “estrutural” e “impede entrega responsável”.
